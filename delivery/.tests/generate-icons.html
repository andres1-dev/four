Genera automáticamente los PNG desde el SVG maskable

📋 Iconos a Generar

Se generarán 4 tamaños PNG desde icon-maskable.svg:

  • 192x192px - Para Android y pantallas pequeñas
  • 256x256px - Tamaño intermedio
  • 384x384px - Para pantallas de alta resolución
  • 512x512px - Máxima calidad

📝 Instrucciones de Descarga

  1. Haz clic en "Generar Todos los PNG"
  2. Espera a que se generen los 4 iconos
  3. Haz clic derecho en cada imagen → "Guardar imagen como..."
  4. Guarda cada imagen con el nombre correcto:
    • icon-192.png
    • icon-256.png
    • icon-384.png
    • icon-512.png
  5. Coloca todos los archivos en la carpeta icons/
  6. El manifest.json ya está actualizado para usarlos
