🚀 PASOS RÁPIDOS (15 MINUTOS):

  1️⃣  Ir a Firebase Console
      → https://console.firebase.google.com/
      → Crear proyecto "sistema-documentos"

  2️⃣  Crear Realtime Database
      → Modo de prueba
      → Reglas públicas (read: true, write: true)

  3️⃣  Obtener Configuración
      → Registrar app web
      → Copiar firebaseConfig

  4️⃣  Editar js/firebase-config.js
      → Pegar tu configuración
      → Guardar

  5️⃣  Subir a GitHub
      → git add .
      → git commit -m "Add Firebase sync"
      → git push

  6️⃣  Probar
      → Abre test-firebase.html
      → Clic en "Probar Conexión"
      → Debe decir "✅ Firebase funcionando"
