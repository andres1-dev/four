  2️⃣  Verificar
      → Usa: icons/CHECKLIST.md
      → Confirma que tienes los 5 PNG

  3️⃣  Subir a GitHub
      → git add .
      → git commit -m "Add PWA support"
      → git push

  4️⃣  Activar GitHub Pages
      → Settings → Pages → Selecciona rama → Save

  5️⃣  Probar
      → Abre tu URL de GitHub Pages
      → Instala la PWA (ícono ➕ en navegador)
      → Prueba sincronización en dos pestañas

🐛 SOLUCIÓN RÁPIDA:

  Problema: SW no se registra
  → Verifica HTTPS y consola del navegador

  Problema: Iconos no aparecen
  → Genera los PNG con icons/generate-icons.html

  Problema: No sincroniza
  → Verifica que SW esté "activated" en DevTools

  Problema: No se puede instalar
  → Verifica que los iconos estén en icons/
