🔒 Verificador de Seguridad Firebase

Esta herramienta verifica la configuración de seguridad de tu Firebase.

📋 Reglas Recomendadas

Copia estas reglas en Firebase Console → Realtime Database → Reglas:

{ "rules": { "sistema-documentos": { "sync-events": { ".read": true, ".write": true, ".indexOn": ["timestamp"], "$eventId": { ".validate": "newData.hasChildren(['action', 'timestamp', 'id'])" } } } } }

Pasos:

  1. Ve a Firebase Console
  2. Selecciona tu proyecto
  3. Ve a Realtime Database → Reglas
  4. Pega las reglas de arriba
  5. Haz clic en "Publicar"
