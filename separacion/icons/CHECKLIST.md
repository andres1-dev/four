# ✅ Checklist de Iconos

Marca cada paso cuando lo completes:

## Generación de Iconos

- [ ] Abrí `generate-icons.html` en el navegador
- [ ] Vi el preview de los 5 iconos
- [ ] Hice clic en "Generar y Descargar Todos los Iconos"
- [ ] Se descargaron 5 archivos PNG

## Archivos Descargados

Verifica que tengas estos archivos en tu carpeta de descargas:

- [ ] `favicon-16x16.png`
- [ ] `favicon-32x32.png`
- [ ] `apple-touch-icon.png`
- [ ] `icon-192.png`
- [ ] `icon-512.png`

## Instalación

- [ ] Moví todos los PNG a la carpeta `icons/`
- [ ] Los archivos están en la misma carpeta que este CHECKLIST.md

## Verificación Final

Tu carpeta `icons/` debe tener:

```
icons/
├── .gitkeep
├── CHECKLIST.md (este archivo)
├── README.md
├── generate-icons.html
├── favicon-16x16.png ⬅️ Generado
├── favicon-32x32.png ⬅️ Generado
├── apple-touch-icon.png ⬅️ Generado
├── icon-192.png ⬅️ Generado
└── icon-512.png ⬅️ Generado
```
